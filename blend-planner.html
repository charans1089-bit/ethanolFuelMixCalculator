🔧 GITHUB BACKUP WORKFLOW

Follow these steps to store your personal seasonal blend history in your Git repository:

  1. Download the CSV or JSON schedule from the EXPORT HUB above.
  2. Place the downloaded file in your repo’s data/blend-history/ folder.
  3. Run the Git commands below in your terminal to commit and push.
mkdir -p data/blend-history
mv ~/Downloads/SCRK_BlendSchedule_2026.csv data/blend-history/
git add data/blend-history/
git commit -m "telemetry: seasonal blend snapshot"
git push origin main
